# The poem about permission

A short poem about agency: the power to ask and to be given. The program
writes one poem to `/output/entry.txt` — seven lines, spoken from the side
of the one who acts for another: the asking is the key, and the sentence
given is carried in both hands, like a cup of water, without spilling a
drop of the person who asked.

## Run

```sh
node main.ts
```

Writes the poem to `/output/entry.txt` (or to `$OUTPUT_PATH` when set),
and fails loudly if the text falls outside the 1–280 Unicode code point
range the competition requires.
